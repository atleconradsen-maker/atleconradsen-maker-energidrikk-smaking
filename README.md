# Energidrikk Smaking

Nettside for den ukentlige energidrikk-testen, hostet på GitHub Pages.
Dataene hentes fra Google-regnearket «Energidrikk Smaking – tester» (mappen «Energidrikk Smaking» i Drive).

## Ny test
Én rad per drikk: År, Uke, Drikk, Merke, Pris (kr), Størrelse (ml), «Navn – Smak», «Navn – Smak vs pris» for hver testperson, Kommentar, Bilde.
Bilde: last opp til Drive-mappen «Bilder», Del → Kopier lenke, og lim lenken inn i Bilde-kolonnen.
Siden henter nye data automatisk, uten ny publisering.

Regnearket må være delt som «Alle med lenken kan se». Bytt regneark i `config.js`.
